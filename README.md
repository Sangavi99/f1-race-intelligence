# F1 Race Intelligence Platform

## Project Overview

An end-to-end Formula 1 data engineering and AI project that transforms publicly available race data into reliable datasets and useful motorsport insights.

## Objectives

- Ingest public F1 race data.
- Build a reliable ETL pipeline using Python.
- Validate and transform race data.
- Store data in Google BigQuery.
- Orchestrate workflows with Apache Airflow.
- Analyse lap pace, tyre stints and pit-stop performance.
- Develop an evaluated AI/ML feature.
- Serve insights through an API and dashboard.

## Technology Stack

- Python
- SQL / GoogleSQL
- Google BigQuery
- Apache Airflow
- Pandas and NumPy
- scikit-learn
- FastAPI
- Next.js
- Docker
- Git

## Initial Scope

The first version will use batch processing and historical F1 data as a fallback when the latest session data is unavailable.
